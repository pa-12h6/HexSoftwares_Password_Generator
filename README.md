# HexSoftwares Password Generator

## Project Overview

This project is developed as part of the HexSoftwares Python Programming Internship.

The Password Generator is a Python-based application that creates strong random passwords using letters, numbers, and symbols.

## Features

* Generates random passwords
* Allows the user to select password length
* Supports uppercase and lowercase letters
* Option to include numbers
* Option to include symbols
* Validates the password length
* Provides a simple command-line interface

## Technologies Used

* Python
* Random Library
* String Library

## How It Works

The application asks the user to enter the required password length.

The user can then choose whether numbers and symbols should be included.

The program uses Python's `random` and `string` libraries to create a random password from the selected characters.

## How to Run

### Step 1: Install Python

Make sure Python is installed on your computer.

Check the installation using:

```bash
python --version
```

### Step 2: Clone the Repository

Clone this repository using:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Step 3: Open the Project Folder

```bash
cd HexSoftwares_Password_Generator
```

### Step 4: Run the Program

```bash
python password_generator.py
```
